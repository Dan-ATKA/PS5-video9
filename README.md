# PS5-video9
A video converter for consoles, mainly on consoles. Aim to be available for PS5, PS4, and PS3. Maybe others. And on PC also, mainly Debian based Linux.

## Ideas
Should be similar to handbrake in possibilities, even if the name is a nod to PSP Video9. 
Software codecs first.
Preset should aim for best quality/size ratio because storage is at premium these day.
Batch processing for seasons.

## When done...
Add a browser and equivalent to ytdlp or video download helper to get video from streaming website and convert to archival offline usable formats without computer
